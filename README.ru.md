# Antigravity Transcript Viewer

> **Смотрите в реальном времени, что именно видит, делает и тратит ваш ИИ-агент.**  
> Быстрый локальный просмотрщик логов сессий Google Antigravity для Windows, Linux и macOS без установки сторонних пакетов.

[🇬🇧 Read in English](README.md) · [🤖 Архитектура для разработчиков и ИИ-агентов](PROJECT_ARCHITECTURE.md)

## Зачем это нужно

Antigravity записывает каждый шаг работы — ваши запросы, скрытые рассуждения агента, вызовы инструментов, правки файлов, сжатия контекста и статистику токенов — в большие нечитаемые JSONL-файлы.

**Antigravity Transcript Viewer** превращает эти логи в удобную рабочую панель в браузере:

### Живое чтение и быстрая навигация
- **Обновление в реальном времени:** новые сообщения и ответы инструментов появляются сразу по мере работы агента, не мешая ему писать лог. Если вы отмотали историю вверх, мигающая кнопка **`↓ К новому сообщению`** перенесёт прямо к первому непрочитанному шагу.
- **Скорость на огромных логах:** десятки тысяч шагов листаются плавно без подвисаний и тормозов вкладки.
- **Оглавление и миникарта скроллбара:** переходите к нужному месту из верхнего оглавления или по цветным зарубкам справа (`💬` ваши запросы, `📦` сжатия контекста, `⚠` ошибки команд, `★` выбранное на карте команд) — при наведении виден текст, по клику происходит переход.
- **Режим «Диалог»:** скрывает промежуточную рутину и оставляет только переписку «Вы ↔ Финальные ответы ИИ» с кнопкой раскрытия мыслей и вызовов инструментов между сообщениями.
- **Мгновенный поиск (`/`):** ищет по тексту, мыслям агента, командам, параметрам, выводам (`EXIT: 1`), номерам `#шагов` и времени, подсвечивая совпадения в ленте и в оглавлении.

### Инструменты, код, Diff и файлы
- **Связанные вызовы и заметные ошибки:** ответ инструмента привязывается прямо под его вызовом. Шаги со сбоями сразу выделяются сине-жёлтой диагональной рамкой, крупными значками `✓` / `⚠` и плашками `exit: 0` / `EXIT: N`.
- **Читаемый код, Markdown и правки:**
  - `edit_file` показывает построчный diff (удалённое зачёркнуто, новое — **жирным**, изменённое — *курсивом*) и сразу прокручивает блок к новой части (`Replacement`).
  - `read_file` отображает `.md` как Markdown, а исходный код — моноширинным шрифтом с построчной нумерацией, которая не мешает копировать код.
  - Глобальная настройка отображения под оглавлением (**В прокрутке**, **Полностью** или **Скрыть**) и кнопки **«Показать полностью / Свернуть в прокрутку»**, которые появляются только там, где содержимое реально не помещается.
  - Оглавление вверху прокручивается колёсиком сразу при наведении, а внутренние блоки кода/параметров захватывают колёсико только после клика внутрь — чтобы не перехватывать обычный скролл ленты.
- **Безопасное копирование в терминал:** кнопки копирования убирают лишний перевод строки в конце, чтобы вставленная команда не запустилась сама собой. Для многострочных команд есть кнопки **`Copy &&`** (в одну строку) и **`Copy { ; }`** (блок PowerShell). Служебные префиксы вроде `pwsh -c` приглушены, чтобы сразу видеть суть команды.
- **Картинки по ширине окна:** скриншоты и встроенные изображения вписываются в ширину экрана без горизонтального скролла и открываются в полном размере по клику.
- **Кликабельные ссылки и просмотр файлов:** веб-ссылки, локальные пути и имена файлов проекта становятся кликабельными. По клику на файл можно выбрать **просмотр с форматированием в браузере**, **чистый текст (Raw)** или **системную программу** (с запоминанием выбора и настройкой открытия папок в браузере, Проводнике или Total Commander).
- **Точное местное время и исходный JSON (`{ }`):** время шагов автоматически подстраивается под ваш часовой пояс (при наведении виден исходный UTC). Кнопка `{ }` или **`Shift + ПКМ`** открывает оригинальный JSON карточки прямо на месте, не ломая обычное меню правой кнопки мыши.

### Аналитика токенов и кэша
- **Эффективность кэша промпта:** каждый шаг модели показывает `input`, `cache_read`, `output` и процент попадания в кэш с контрастной градацией серого (удобно при дальтонизме).
- **График пауз (`Δt`):** в шапке сессии видно, после каких перерывов кэш остыл и вырос расход входных токенов.
- **📊 Карта команд:** полная сводка по типам шагов, статусам и использованным инструментам (`✓` / `⚠` и список файлов). Выбранные команды можно подсветить `★` на полосе справа или отфильтровать по ним всю ленту.

### Удобство чтения и ввод сообщений
- **Встроенное поле ввода → `Antigravity.exe` (Windows):** высоту поля можно менять перетаскиванием, `Shift+Enter` переносит строку, а **`Enter`** копирует текст, переключается на окно `Antigravity.exe` и вставляет сообщение **без отправки**. На Linux и macOS по `Enter` текст копируется в буфер обмена.
- **Максимум пространства и две темы:** боковая панель (`«`), верхняя панель (`▲`) и нижнее поле ввода (`▼`) сворачиваются независимо. Доступны контрастная **тёмная** и мягкая **дневная** тема.

## Быстрый старт (Windows / Linux / macOS)

1. Убедитесь, что установлен **Python 3.10+** (дополнительные библиотеки и Node.js не требуются).
2. Скачайте репозиторий и запустите **`run.bat`** (Windows), **`./run.sh`** (Linux/macOS) или выполните:

```bash
python server.py      # Windows
python3 server.py     # Linux / macOS
```

3. Браузер автоматически откроет `http://127.0.0.1:8765/` со списком всех сессий, отсортированных по дате последнего обновления.

### Параметры запуска

| Флаг | По умолчанию | Описание |
| :--- | :--- | :--- |
| `--port` | `8765` | Локальный HTTP-порт |
| `--host` | `127.0.0.1` | Адрес привязки (по умолчанию только localhost) |
| `--brain-dir` | `~/.gemini/antigravity/brain` | Свой путь к папке `brain` |
| `--no-open` | `false` | Запустить сервер без автооткрытия вкладки |
| `--check` | `false` | Проверить поиск и чтение логов и выйти |

## Горячие клавиши

- **`/`** — перейти в строку поиска по логу.
- **`PgDn` / `PgUp` / `Home` / `End`** — прокрутка ленты независимо от фокуса кнопок.
- **`{ }`** или **`Shift + ПКМ`** — показать/скрыть исходный JSON шага или ответа.
- **Наведение 1.2 сек** на бейдж или имя параметра — подробная подсказка.
- **`Enter` / `Shift+Enter`** в нижнем поле — вставить в Antigravity (или скопировать в буфер) / перенос строки.
- **`Esc`** — закрыть окно карты команд, картинку, подсказку или снять фокус с внутреннего скролл-блока.

## Приватность и платформы

- **Только локально:** сервер слушает только `127.0.0.1`, читает логи в режиме «только чтение» и никуда не отправляет данные.
- **Кроссплатформенность:** просмотр логов, live-обновление, поиск, diff, Markdown и карта команд полностью работают на Windows, Linux и macOS. Функции Windows (Проводник/TotalCmd и автовставка в `Antigravity.exe`) на Linux и macOS автоматически адаптируются под системный файловый менеджер и буфер обмена.
